3. Seguridad Web, OWASP y Remediación (Tomo II)

Clase de vulnerabilidadCausa raíz típicaRemediación definitiva (Estándar OWASP)
SQL Injection (SQLi)Concatenar entrada del usuario en la cadena SQL.Consultas parametrizadas (Prepared Statements) en el 100 % de las queries + mínimo privilegio en BD.
Cross-Site Scripting (XSS)Reflejar o almacenar datos no confiables en HTML/JS sin escape contextual.Escape automático contextual (Jinja2/React) + cabecera Content-Security-Policy con nonces + cookie HttpOnly.
CSRFConfiar únicamente en cookies enviadas automáticamente en peticiones de cambio de estado.Cookies con SameSite=Lax o Strict + token anti-CSRF sincronizado por sesión.
IDOR / BOLAUsar un ID directo (/ticket/42) sin verificar si pertenece al usuario autenticado.Comprobar propiedad en el servidor en cada consulta (WHERE id = ? AND owner_id = ?) + pruebas unitarias de autorización.
SSRFHacer peticiones HTTP desde el backend a URLs arbitrarias provistas por el cliente.Lista blanca estricta de esquemas/dominios + bloqueo de rangos privados (127.0.0.0/8, 169.254.169.254, RFC 1918).
JWT inseguroAceptar alg: none, claves HMAC débiles o no validar exp/iss/aud.Fijar algoritmo explícito en el servidor, rotación de claves largas y expiraciones cortas.
Path Traversal / UploadConstruir rutas de archivo desde el nombre subido o servir uploads desde webroot.Renombrar con UUID, validar tipo MIME real (magic bytes), guardar fuera de webroot y resolver realpath dentro del directorio base.

Integridad y autenticidadHMAC-SHA256 (comparar con hmac.compare_digest)Hash plano sin clave secreta o comparación con ==
Hashing de contraseñasArgon2id (o bcrypt/scrypt con salt único)MD5, SHA-1, SHA-256 directo sin factor de costo
Firmas digitales e intercambioEd25519, ECDSA P-256, RSA-PSS ≥ 2048, ECDHEClaves RSA < 2048 bits, curvas débiles, TLS sin PFS
Protocolo TLSTLS 1.3 y TLS 1.2 con suites AEAD + ECDHESSLv2, SSLv3, TLS 1.0, TLS 1.1
# Inspeccionar campos críticos (Emisor, Validez, SAN) de un certificado PEM local
openssl x509 -in cert.pem -noout -subject -issuer -dates -ext subjectAltName

# Verificar conexión TLS 1.3 y cadena de certificados contra un servicio local
openssl s_client -connect 127.0.0.1:8443 -tls1_3 -showcerts </dev/null

# Calcular hash SHA-256 de integridad sobre un artefacto o evidencia DFIR
sha256sum evidencia.raw
