Glosario técnico (116 términos esenciales)

Definiciones claras y directas de los conceptos fundamentales de redes, pentesting, web avanzada, Code Review, Active Directory, SOC/DFIR, Cloud/Kubernetes, Mobile, Wi-Fi, OT/ICS y GRC usados a lo largo de los 7 tomos.

TérminoDefinición técnica
802.1X / EAP-TLSEstándar de control de acceso a red cableada e inalámbrica basado en RADIUS; EAP-TLS exige autenticación mutua mediante certificados digitales tanto del servidor como del cliente.
ACL / DACLAccess Control List / Discretionary ACL. Lista de entradas de control de acceso que define qué usuarios o grupos tienen permisos (lectura, escritura, control total) sobre un archivo NTFS, servicio u objeto de Active Directory.
ADCSActive Directory Certificate Services. Infraestructura de clave pública (PKI) de Microsoft integrada en AD que emite certificados digitales; una mala configuración en sus plantillas (ESC1–ESC8) puede permitir escalada a Domain Admin.
AEADAuthenticated Encryption with Associated Data. Familia de modos criptográficos modernos (AES-GCM, ChaCha20-Poly1305) que garantizan confidencialidad, integridad y autenticidad en una sola operación.
AES-GCMModo Galois/Counter Mode para AES; estándar AEAD de alto rendimiento que cifra datos y genera una etiqueta criptográfica de autenticación (requiere no repetir nunca la pareja Clave + Nonce).
AMSIAntimalware Scan Interface. Interfaz de Windows que permite a motores de scripting (PowerShell, WSH, .NET) enviar contenido dinámico ya desofuscado al antivirus/EDR antes de ejecutarlo.
ARPAddress Resolution Protocol. Protocolo de capa 2/3 que traduce una dirección IPv4 a su dirección física MAC dentro de un mismo segmento de red local.
AS-REP RoastingTécnica de auditoría en Kerberos contra cuentas que tienen deshabilitada la preautenticación; permite solicitar un bloque cifrado con el hash del usuario para evaluar la fortaleza de su contraseña offline.
ATT&CK (MITRE)Base de conocimiento abierta de tácticas, técnicas y procedimientos (TTPs) observados en intrusiones reales, usada por Red Teams y SOCs para mapear detecciones y brechas de visibilidad.
auditdDemonio de auditoría del kernel de Linux que registra llamadas al sistema, accesos a archivos críticos, cambios de privilegios y ejecuciones de comandos para monitoreo defensivo y DFIR.
BFLA / BOLABroken Function Level Authorization / Broken Object Level Authorization. Fallos críticos de OWASP API Top 10 donde un usuario accede a funciones administrativas o a objetos de otro usuario cambiando identificadores.
BloodHoundHerramienta basada en teoría de grafos que mapea relaciones de permisos, sesiones y membresías en Active Directory para identificar rutas de escalada y planificar su remediación.
Bucket Policy / Public Access BlockControles de autorización sobre almacenamiento en la nube (como AWS S3) que definen quién puede leer o escribir objetos y bloquean exposiciones públicas accidentales.
Bug Bounty / VDPProgramas públicos o privados (HackerOne, Bugcrowd, Intigriti) donde investigadores reportan vulnerabilidades dentro de una Policy y Scope explícitos a cambio de recompensas o reconocimiento (VDP).
Capabilities (Linux)Mecanismo del kernel de Linux que divide los privilegios de root en permisos granulares (como cap_net_bind_service o cap_setuid) asignables a binarios específicos.
CIDRClassless Inter-Domain Routing. Notación de subredes (ej. 192.168.56.0/24) que indica cuántos bits corresponden a la porción de red y cuántos a los hosts.
CIM / ECSCommon Information Model (Splunk) y Elastic Common Schema (Elastic). Esquemas de normalización de campos que permiten correlacionar logs heterogéneos (firewall, Windows, Linux) bajo nombres uniformes.
Container EscapeFallo de aislamiento (por --privileged, capacidades excesivas o montaje de docker.sock) que permite salir del namespace del contenedor y tomar control del sistema anfitrión.
CORSCross-Origin Resource Sharing. Mecanismo basado en cabeceras HTTP que relaja controladamente la política del mismo origen (SOP) para permitir peticiones entre distintos dominios.
CSPContent Security Policy. Cabecera HTTP defensiva que restringe qué orígenes de scripts, estilos, imágenes y marcos puede cargar el navegador, mitigando el impacto de XSS.
CSRFCross-Site Request Forgery. Vulnerabilidad web que induce al navegador de un usuario autenticado a enviar una petición no deseada aprovechando que las cookies se adjuntan automáticamente.
CSWSHCross-Site WebSocket Hijacking. Variante de CSRF aplicada sobre el handshake inicial Upgrade: websocket cuando el servidor no valida la cabecera Origin ni tokens anti-CSRF.
CTICyber Threat Intelligence. Recolección, análisis y contextualización de información sobre amenazas, campañas, TTPs e indicadores (IOCs) para apoyar decisiones defensivas.
CVSS / EPSSCommon Vulnerability Scoring System (mide severidad técnica intrínseca 0–10) y Exploit Prediction Scoring System (estima probabilidad estadística de explotación activa en los próximos 30 días).
Data DiodeDispositivo o enlace físico unidireccional usado en entornos OT/SCADA críticos para exportar telemetría hacia redes corporativas sin permitir jamás tráfico de retorno hacia planta.
DCSyncTécnica que abusa de los permisos de replicación de Active Directory (MS-DRSR) para solicitar hashes de credenciales a un Controlador de Dominio simulando ser otro DC.
DefangingPráctica segura en SOC/CTI de desactivar URLs o IPs sospechosas al documentarlas (ej. hxxp://ejemplo[.]invalid) para evitar clics accidentales.
Detection-as-CodePráctica de ingeniería que gestiona reglas de detección (Sigma, YARA, Suricata, SPL) con control de versiones Git, revisiones de pares y pruebas automatizadas.
DFIRDigital Forensics and Incident Response. Disciplina que combina la respuesta y contención ante incidentes con la preservación y análisis forense de evidencia en disco, memoria y red.
DLL HijackingDebilidad en Windows donde una aplicación carga una biblioteca DLL mal ubicada aprovechando el orden de búsqueda de directorios cuando existen permisos de escritura inadecuados.
DNSDomain Name System. Sistema jerárquico distribuido que traduce nombres de dominio a direcciones IP y almacena registros de correo (MX, SPF, DKIM, DMARC) y servicios (SRV en AD).
DOM ClobberingTécnica web que inyecta elementos HTML con atributos id o name para sobrescribir variables globales esperadas por scripts del cliente y alterar su flujo de ejecución.
Entra IDServicio de identidad y acceso en la nube de Microsoft (antes Azure AD) que gestiona usuarios híbridos, Service Principals, tokens OIDC/OAuth y políticas de Acceso Condicional.
EPAExtended Protection for Authentication. Mecanismo de seguridad en Windows que vincula la autenticación NTLM/Kerberos al canal TLS externo para prevenir ataques de relay.
ETWEvent Tracing for Windows. Subsistema nativo de telemetría de alto rendimiento integrado en el kernel y user mode de Windows, clave para EDRs y análisis de comportamiento.
EVTXFormato binario XML de los registros de eventos modernos de Windows ubicados en C:\Windows\System32\winevt\Logs\.
Falso Positivo (FP)Alerta disparada por un SIEM o IDS ante actividad legítima y benigna. Reducir falsos positivos mediante afinado es esencial para evitar fatiga de alertas en el SOC.
Forward Secrecy (PFS)Propiedad de intercambio de claves efímero (ECDHE) en TLS 1.2/1.3 que impide descifrar tráfico capturado en el pasado aunque la clave privada del servidor sea comprometida en el futuro.
FridaToolkit de instrumentación dinámica multiplataforma usado en pruebas móviles autorizadas (Android/iOS) para inspeccionar llamadas en memoria, WebViews y validaciones TLS en emulador.
Fuzzing WebTécnica automatizada de enviar listas controladas de rutas, vhosts o parámetros contra una aplicación autorizada (ej. con ffuf) para descubrir superficie expuesta o comportamientos anómalos.
gMSAGroup Managed Service Account. Cuenta de servicio de Active Directory cuya contraseña de 120 bytes es gestionada y rotada automáticamente por el dominio, eliminando el riesgo de Kerberoasting.
GPOGroup Policy Object. Objeto de configuración centralizada en Active Directory que aplica políticas de seguridad, scripts y configuraciones a equipos y usuarios de una OU.
GraphQLLenguaje de consulta para APIs que expone un esquema tipado en un único endpoint; requiere controles explícitos de autorización por resolver, límite de profundidad y desactivación de introspección en producción.
GRCGovernance, Risk and Compliance. Disciplina que alinea la ciberseguridad con los objetivos del negocio, la cuantificación de riesgos (SLE/ALE) y marcos como ISO 27001, NIST CSF 2.0 y GDPR.
HardeningProceso sistemático de reducir la superficie de ataque de un sistema operativo, aplicación o dominio eliminando servicios innecesarios, aplicando mínimo privilegio y fortaleciendo configuraciones.
Hash (Criptográfico)Función matemática unidireccional de tamaño fijo (ej. SHA-256) usada para verificar integridad de archivos y evidencias. Para contraseñas se requieren KDF lentos con salt como Argon2id.
HMACHash-based Message Authentication Code (RFC 2104). Código de autenticación calculado con un hash y una clave secreta compartida para verificar integridad y autenticidad sin cifrar el contenido.
HttpOnly / SameSiteAtributos defensivos de cookies: HttpOnly impide leer la cookie desde JavaScript (mitiga robo por XSS); SameSite controla su envío en peticiones entre sitios (mitiga CSRF).
IDORInsecure Direct Object Reference. Subtipo clásico de fallo de autorización donde modificar un identificador visible permite acceder a recursos pertenecientes a otro usuario.
IDS / IPSIntrusion Detection System (monitorea y alerta tráfico anómalo en pasivo) e Intrusion Prevention System (opera en línea y puede bloquear tráfico malicioso, ej. Suricata).
IMDSv2Instance Metadata Service v2 en AWS; sustituye peticiones GET simples de metadatos por un flujo con token de sesión PUT y límite de saltos (hop-limit 1) para mitigar SSRF hacia credenciales IAM.
IOCIndicator of Compromise. Artefacto observable (hash SHA-256, IP, dominio, clave de registro) que sugiere una posible intrusión. Ocupa la base de la Pirámide del Dolor por ser fácil de cambiar.
IOMMU / Kernel DMA ProtectionMecanismo de hardware y sistema operativo que aísla la memoria frente a dispositivos PCIe/Thunderbolt conectados físicamente, bloqueando ataques DMA en frío.
ISO/IEC 27001Estándar internacional de referencia para diseñar, operar y auditar un Sistema de Gestión de Seguridad de la Información (SGSI) basado en riesgos y controles del Anexo A.
JWTJSON Web Token. Estándar abierto (RFC 7519) para transmitir claims firmados (header.payload.signature) usado en autenticación stateless y OAuth/OIDC.
KerberoastingTécnica de auditoría en AD que solicita tickets de servicio (TGS) para cuentas con SPN registrado; si la cuenta usa cifrado débil o contraseña corta, puede exponerse offline.
KerberosProtocolo de autenticación mutua basado en tickets (TGT y TGS) emitidos por el Key Distribution Center (KDC) en Active Directory, diseñado para evitar enviar contraseñas por la red.
KQL / SPLKibana Query Language (Elastic) y Search Processing Language (Splunk). Lenguajes de consulta usados por analistas SOC e ingenieros de detección para investigar eventos en el SIEM.
LDAP / LDAPSLightweight Directory Access Protocol (389) y su variante cifrada sobre TLS (636). Protocolo estándar para consultar y administrar objetos en Active Directory.
LFI / Path TraversalLocal File Inclusion / Traversal de rutas. Debilidad donde una entrada no saneada con secuencias como ../ permite leer archivos del sistema fuera del directorio previsto.
LOLBinsLiving-off-the-Land Binaries. Herramientas legítimas y firmadas del propio sistema operativo (como certutil, powershell, mshta o curl) que los atacantes reutilizan para pasar desapercibidos.
MFT ($MFT)Master File Table. Estructura central del sistema de archivos NTFS que registra metadatos, permisos y marcas temporales (timestamps) de todos los archivos del volumen; vital en DFIR.
Modbus / DNP3 / OPC UAProtocolos industriales OT/SCADA; Modbus y DNP3 clásicos carecen de cifrado y autenticación nativa, por lo que exigen segmentación estricta y monitoreo pasivo.
Modelo Purdue (ISA-95)Arquitectura jerárquica de referencia (Niveles 0 a 5 más DMZ Industrial en 3.5) para segmentar maquinaria física OT respecto de la red corporativa IT.
MTTD / MTTRMean Time to Detect (tiempo medio de detección) y Mean Time to Respond/Recover (tiempo medio de respuesta/contención). Métricas operativas clave de eficacia de un SOC.
Namespaces y cgroupsPrimitivas del kernel Linux sobre las que funcionan los contenedores: namespaces aíslan qué ve cada proceso (PID, red, montajes) y cgroups limitan los recursos físicos que consume.
NetworkPolicy (Kubernetes)Recurso declarativo de Kubernetes que actúa como firewall de capa 3/4 entre Pods y namespaces; sin él, todo el tráfico interno del clúster suele estar permitido por defecto.
NIST CSF 2.0Cybersecurity Framework del NIST estructurado en seis funciones continuas: Govern, Identify, Protect, Detect, Respond y Recover.
NSMNetwork Security Monitoring. Recolección, análisis y correlación continua de datos de red (PCAP, NetFlow, Zeek, IDS) para detectar y responder a intrusiones.
NTLM RelayTécnica de intermediación donde una autenticación NetNTLM entrante se reenvía en tiempo real a otro servidor de la red que no exige firma (SMB/LDAP Signing) ni EPA.
OAuth 2.0 / PKCEProtocolo estándar de autorización delegada; PKCE (Proof Key for Code Exchange) protege el flujo Authorization Code contra intercepción del código de autorización en apps web y móviles.
OPSECOperations Security. Disciplina de minimizar la huella operativa y telemétrica (comandos ruidosos, artefactos en disco, horarios anómalos) durante ejercicios autorizados de Red Team.
OWASP MASTGMobile Application Security Testing Guide. Guía técnica abierta para auditar aplicaciones Android e iOS de forma estática y dinámica.
OWASP WSTG / ASVSWeb Security Testing Guide (metodología de pruebas web) y Application Security Verification Standard (requisitos verificables de arquitectura y código seguro).
PASTAProcess for Attack Simulation and Threat Analysis. Metodología de modelado de amenazas en siete etapas centrada en el riesgo real del negocio y la validación de ataques plausibles.
PCAPPacket Capture. Formato de archivo estándar generado por tcpdump o Wireshark que almacena tráfico de red completo para análisis técnico y forense.
Pirámide del DolorModelo de David Bianco que clasifica los indicadores de menor a mayor dificultad de reemplazo para un adversario: Hashes → IPs → Dominios → Artefactos → Herramientas → TTPs.
PivotingTécnica de enrutar tráfico autorizado de auditoría a través de un host intermedio en un laboratorio segmentado (mediante túneles SSH o SOCKS5) para alcanzar una subred interna.
PKI / Certificado X.509Public Key Infrastructure. Sistema de Autoridades de Certificación (CA) que firman certificados digitales X.509 v3 (RFC 5280) vinculando identidades DNS o usuarios con sus claves públicas.
PMKIDIdentificador derivado en el primer paquete EAPOL del handshake WPA/WPA2; su captura en APs vulnerables permite evaluar la robustez de la contraseña offline sin esperar un cliente conectado.
Pod Security StandardsNiveles oficiales de endurecimiento de Kubernetes (Privileged, Baseline y Restricted) orientados a impedir contenedores privilegiados, escaladas de privilegio y acceso al host.
PPID SpoofingTécnica inspeccionada en ingeniería de detección donde un proceso hijo declara un identificador de proceso padre falso para simular legitimidad frente a reglas simplistas del SOC.
Prefetch / ShimCacheArtefactos nativos de Windows que registran evidencia histórica de programas ejecutados en el equipo, esenciales en investigaciones DFIR incluso si el binario fue borrado.
Protected UsersGrupo de seguridad de Active Directory que endurece cuentas privilegiadas bloqueando NTLM, deshabilitando delegación y reduciendo el tiempo de vida de tickets Kerberos.
Race Condition (Single-Packet)Condición de carrera avanzada sobre HTTP/2 que agrupa decenas de solicitudes en un solo paquete TCP para hacerlas llegar simultáneamente en microsegundos al backend.
RBAC (Kubernetes)Role-Based Access Control en Kubernetes; regula mediante Roles, ClusterRoles y Bindings qué acciones puede ejecutar cada usuario o ServiceAccount sobre la API del clúster.
RBCDResource-Based Constrained Delegation. Mecanismo de delegación Kerberos configurado en el recurso destino (msDS-AllowedToActOnBehalfOfOtherIdentity) que debe auditarse estrictamente.
RoE (Rules of Engagement)Documento contractual y técnico previo a una auditoría que fija alcance exacto (IPs/dominios), ventanas horarias, contactos de emergencia y límites estrictos.
SAN (Subject Alternative Name)Extensión estándar X.509 que enumera los nombres DNS, IPs o UPNs válidos para un certificado digital TLS o PKINIT.
SAST / DAST / SCA / SBOMPruebas automatizadas DevSecOps: análisis estático de código (SAST), dinámico en ejecución (DAST), composición de dependencias (SCA) e inventario de componentes (SBOM).
SIEMSecurity Information and Event Management. Plataforma centralizada (como Splunk o Elastic Security) que recopila, normaliza, almacena y correlaciona logs para generar alertas SOC.
SigmaFormato abierto y agnóstico basado en YAML para describir reglas de detección sobre logs, convertible automáticamente a consultas de múltiples SIEMs (SPL, KQL, Sentinel).
SMB SigningMecanismo criptográfico del protocolo SMB que firma cada paquete para garantizar integridad y autenticidad, bloqueando ataques de NTLM Relay hacia SMB.
SnapshotInstantánea del estado de disco y configuración de una máquina virtual en un instante dado, permitiendo volver a un entorno limpio en segundos.
Source → SinkTrazado fundamental en revisión White-Box que sigue el recorrido de un dato externo desde su punto de entrada (Source) hasta una función sensible (Sink) verificando sanitización.
SPF / DKIM / DMARCEstándares de autenticación de correo electrónico: SPF valida IPs autorizadas por DNS, DKIM firma criptográficamente el mensaje y DMARC exige alineación del dominio visible From.
SPNService Principal Name. Identificador único de una instancia de servicio registrado en una cuenta de Active Directory para asociarlo a tickets Kerberos.
SQL Injection (SQLi)Vulnerabilidad crítica causada por concatenar datos de usuario en sentencias SQL sin parametrización, permitiendo alterar la lógica de la consulta o extraer datos.
SSRFServer-Side Request Forgery. Fallo donde el servidor realiza peticiones de red hacia destinos internos o externos controlados por el atacante.
SSTIServer-Side Template Injection. Vulnerabilidad que ocurre al incrustar entrada no confiable directamente como plantilla en motores como Jinja2 o Twig en lugar de pasarla como variable.
STRIDEModelo mnemotécnico de amenazas por componente: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service y Elevation of Privilege.
Subdomain TakeoverVulnerabilidad que ocurre cuando un registro DNS CNAME apunta a un recurso SaaS o Cloud externo dado de baja y aún reclamable, permitiendo servir contenido bajo el subdominio de la organización.
SUID / SGIDBits especiales de permisos en Unix/Linux que ejecutan un binario con los privilegios efectivos de su propietario (usualmente root) o grupo.
SysmonSystem Monitor (Microsoft Sysinternals). Servicio y driver del sistema que enriquece Windows Event Log con telemetría detallada de procesos, red, DLLs, acceso a procesos y DNS.
Threat HuntingBúsqueda proactiva y guiada por hipótesis de amenazas ocultas o TTPs no detectados aún por las alertas automáticas del SOC.
Tiering (Tier 0/1/2)Modelo de administración segregada de Active Directory que impide iniciar sesión con credenciales de Tier 0 (Domain Admins/DCs) en servidores (Tier 1) o estaciones de trabajo (Tier 2).
TimestompingAlteración deliberada de marcas temporales de un archivo en disco ($STANDARD_INFORMATION), detectable comparándolas contra $FILE_NAME, $UsnJrnl y Prefetch.
UART / JTAG / SPIInterfaces físicas habituales en placas IoT y hardware embebido usadas respectivamente para consola serie de depuración, control de procesador en placa y lectura de memorias flash.
UnhookingConcepto defensivo/ofensivo referido a restaurar bytes originales de bibliotecas del sistema (como ntdll.dll) cuando han sido interceptados en modo usuario por hooks de monitoreo.
Volatility 3Framework abierto en Python para el análisis forense de volcados de memoria RAM (procesos ocultos, sockets, DLLs inyectadas y artefactos volátiles).
Web Cache Poisoning / DeceptionAtaques a cachés HTTP/CDN: el Poisoning fuerza a guardar una respuesta manipulada para otros usuarios usando cabeceras no incluidas en la cache key; el Deception engaña a la caché para almacenar datos privados.
WPA3-SAEEstándar Wi-Fi moderno basado en Simultaneous Authentication of Equals (Dragonfly) que sustituye PSK clásico e impide ataques de diccionario offline tras capturar un handshake.
XSSCross-Site Scripting. Vulnerabilidad web que permite inyectar y ejecutar JavaScript no autorizado en el contexto del navegador de la víctima.
XXEXML External Entity. Fallo en parsers XML mal configurados que resuelven entidades externas DTD, permitiendo lectura de archivos locales o SSRF.
YARAHerramienta y lenguaje de reglas basadas en patrones de texto/hexadecimal y condiciones lógicas utilizado para clasificar archivos y realizar triage estático de malware.
ZeekMonitor de análisis de red de código abierto que transforma tráfico de red en logs estructurados de alto nivel (conn.log, dns.log, http.log, ssl.log) ideales para hunting y SIEM.

Manual técnico libre, educativo y defensivo. Todas las prácticas están diseñadas exclusivamente para laboratorios locales aislados (VMs propias o Docker en 127.0.0.1).
