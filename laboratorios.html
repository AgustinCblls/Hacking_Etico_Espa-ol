Kit de laboratorios locales y plantillas

Todas las prácticas de este curso se ejecutan en tu propia máquina virtual aislada o en contenedores locales ligados exclusivamente a 127.0.0.1. La carpeta laboratorios/ reúne los archivos base listos para estudiar y modificar sin depender de internet ni exponer servicios a tu red local.

Regla estricta de entorno local

Los archivos de práctica están configurados para escuchar únicamente en 127.0.0.1 (loopback) o dentro de redes virtuales aisladas (Host-Only / Docker interno). Nunca expongas una aplicación educativa a internet ni ejecutes scripts de auditoría contra sistemas sin autorización escrita previa.

Arranque rápido y pruebas verificables sin descargas externas

# 1. Probar de inmediato el analizador SOC, el auditor White-Box AST y el lab RAG/MCP desde la raíz
python laboratorios/analizador_logs_soc.py laboratorios/muestras/auth_ssh_simulado.log 5
python laboratorios/analizador_logs_soc.py laboratorios/muestras/web_access_simulado.log 4
python laboratorios/auditor_whitebox_codereview.py ./laboratorios/
python laboratorios/lab_rag_mcp_seguro.py

# 2. Levantar la app educativa y Nginx localmente (solo en 127.0.0.1)
cd laboratorios
docker compose up -d

# 3. (Opcional Tomo II) Activar también OWASP Juice Shop local para prácticas web interactivas en 127.0.0.1:3000
docker compose --profile owasp up -d

# 4. Verificar puertos locales y probar endpoints seguros
python auditor_red_local.py 127.0.0.1
curl -s "http://127.0.0.1:5050/buscar-seguro?q=redes"
curl -sI "http://127.0.0.1:5050/saludo-seguro?nombre=Analista"

# 5. Detener contenedores al finalizar la sesión
docker compose --profile owasp down

Manual técnico libre, educativo y defensivo. Todas las prácticas están diseñadas exclusivamente para laboratorios locales aislados (VMs propias o Docker en 127.0.0.1).
